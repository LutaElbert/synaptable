SynapTable turns its visual canvas into a safe workspace for browser agents. The agent first discovers six typed WebMCP tools and reads only a bounded workspace summary. It creates three storyboard concepts, then finds their safe layer IDs without exposing note bodies. Next, it organizes those ideas into a table while preserving the originals, and creates a production table with structured scene data. Rows become new canvas concepts in one atomic action. A single undo removes the entire mutation, redo restores it, and reloading proves that the project was saved locally.
