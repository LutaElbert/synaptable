## Intent

A polished, screen-led SynapTable product demo that begins inside a genuinely empty
project and follows one continuous transformation: capture a thought, grow it into a
connected map, then organize the same thinking into a table. The opening should feel
curious and premium; the close should feel confident and punchy.

## Assets

- `http://localhost:3003` — the real local SynapTable app and the sole source of product UI footage.
- `https://github.com/LutaElbert/synaptable` — product positioning and feature truth.

## Customizations

- Use real screen recording as the primary visual material, beginning on an empty project.
- Generate the voice-over with Google GenAI `gemini-3.1-flash-tts-preview` and the `Orus` voice.
- Use restrained kinetic type, close UI crops, and clean hard cuts around the recorded interface.

## Notes

- Run SynapTable on port 3003 for all capture.
- Creative references: Linear-like precision, Figma-like progressive UI reveal, and Airtable-like workflow-first demonstration. Translate those patterns into SynapTable's own visual language.
- Avoid generic feature-card montages and invented UI.
